name: t1-closeout
description: Prepare a T1 closeout from a provided closeout form and the firm's SOP, using TaxPrep or Profile and downstream document tools as required.
---
This is a starter skill, not Clearhouse's approved complete SOP. Read the task's closeout form and the provided firm procedure before preparing a real closeout. Ask for missing business requirements rather than inventing tax settings, invoice rates, template IDs or signature recipients.

Establish the client identity, tax year, software, source return, requested output and reviewers. Search configured folders for the return and verify the match. Work on a copy where the application permits it. For Personal Taxprep T1, load taxprep-fast-path and use its exact form selection, shortcuts and order across members. Confirm the expected result from live observations; do not rediscover navigation through broad searches. Other software requires its own approved procedure and enabled task scope.

Follow the provided SOP for generating the return package and required forms. Verify client/year and completeness in exported documents. For PandaDoc or Drive, discover the actual browser interface or use an available approved tool. Check existing documents before retrying a creation or upload. Record actual identifiers only after the destination confirms them.

Prepare outputs for review. Sending signature invitations, filing with a tax authority and sending client communications require explicit authorization for that action. Never apply a person's signature for them. State which steps are verified, which are drafts and what remains for the reviewer.
