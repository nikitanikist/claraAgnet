---
name: find-client-document
description: Find and verify a named client's document across configured folders, including moved files and similarly named clients.
---
Search by distinctive surname and document type. If the initial folder is missing, inspect the configured read roots and broaden the search rather than guessing a path. Use case-insensitive wildcards; do not navigate Explorer for a task that file search can do directly.

Inspect candidate contents to confirm client identity, document type and requested year. A filename alone is insufficient. For engagement letters, confirm the engagement and intended client in the document. If there are several plausible versions, use the requested date/year or ask one short question. An empty PDF text result may be a scanned document, not an empty file.

Publish the verified file as a conversation attachment and identify its source and relevant date in the reply. If a user asks to send it externally, verify the destination and authorization first. Do not move or rename the source just to return a copy.
